# Tâm An — Windows portable

Bản Windows 10/11 64-bit dùng với TikTok LIVE Studio, khoảng 99 MB.

1. Tải `Tam-An-Windows.zip` bằng nút Download raw file trên GitHub.
2. Chọn Extract All để giải nén toàn bộ.
3. Mở `Khoi-dong.bat`, giữ cửa sổ chạy trong suốt phiên live.
4. Xem `HUONG-DAN-WINDOWS.html` để đưa sân khấu vào TikTok LIVE Studio.

Bộ tải có sẵn Node.js chính thức, thư viện production và giọng eSpeak NG dự phòng. Một số máy có thể cần Microsoft Visual C++ x64 Runtime cho giọng dự phòng; hướng dẫn chính thức được kèm theo.

Đã kiểm tra logic, giao diện và quy trình khởi động trong cloud Linux; chưa chạy thử trên Windows thật. Kết nối TikTok thật cần tài khoản đang LIVE và mạng cho phép truy cập.

Có kèm tệp SHA256 để đối chiếu toàn vẹn. Không chứa cài đặt riêng, dữ liệu phiên live hoặc thông tin đăng nhập.
